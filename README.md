# JavaHTML 

**JavaHTML** es un entorno de desarrollo integrado (IDE) ligero para escribir y ejecutar código estilo Java directamente en el navegador, sin necesidad de instalar un JDK ni configurar un entorno local.

##  Características

- Editor de código integrado con numeración de líneas.
- Consola de salida para ver los resultados de la ejecución.
- Botones para **Ejecutar** y **Limpiar** el editor/consola.
- Atajo de teclado `Ctrl + Enter` para ejecutar el código rápidamente.
- Interfaz en español, pensada para aprender y probar Java de forma sencilla.
- Funciona completamente en el navegador: solo abre el archivo `javahtml.html`.

##  Cómo usarlo

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en cualquier navegador moderno.
3. Escribe tu código Java en el editor.
4. Pulsa **Ejecutar** o usa `Ctrl + Enter`.
5. Revisa la salida en la consola inferior.

##  Ejemplo básico

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("¡Hola, mundo desde JavaHTML!");
    }
}
```

##  Tecnologías

- HTML5
- CSS3
- JavaScript (vanilla)

No requiere dependencias externas ni procesos de compilación: todo está contenido en un único archivo HTML.
